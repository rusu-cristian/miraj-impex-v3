# FilterBar · Interval period (project addition, SYS01)

When the period SegmentedControl is on Interval, two DateFields appear right after it.

- **Markup:** `.ip-interval[role=group][aria-label=Interval]` > two `.ip-datef` (column: `label.ip-label` above + `.ip-input` holding `<input inputmode="numeric" placeholder="zz.ll.aaaa">` in Plex Mono and the calendar key `button.ip-iconbtn[aria-haspopup=dialog][aria-expanded]`, `aria-controls` = the calendar id while open). The two fields never wrap apart.
- **Labels:** visible, above each field ("de la", "până la"); the filter bar aligns its controls to the fields' row (`align-items:flex-end` when it holds `.ip-interval`).
- **Width:** each field is as wide as `dd.mm.yyyy` in Plex Mono (`10ch`) + padding + a 24px calendar key (about 129px). At 1180px content width the whole bar (period, interval, Zi/Săpt., three RecordChips, Exportă at the right via `.ip-filterbar__end`) stays on one row.
- **Default:** de la = cycle start (10.02.2026), până la = today (16.11.2026). Format `dd.mm.yyyy`.
- **Future dates:** a typed future date is an error: fault edge, `aria-invalid`, and the error line `p.ip-err.ip-filterbar__err` as the bar's last child, a full-width row under the controls, in flow (never over content): "Până la 20.11.2026 e în viitor. Alege o dată până la 16.11.2026." "De la" after "până la" is the same kind of error, naming both dates.
- **Calendar (APG date-picker dialog):** `div.ip-menu.ip-cal[role=dialog][aria-modal=true][aria-label]` > head (◀ IconButton, `h2.ip-cal__title` month with `aria-live=polite`, ▶ IconButton, disabled when the next month is all future) + `table.ip-cal__grid[role=grid][aria-labelledby=month]`: `thead` weekday `th[scope=col][abbr]` L–D, `tbody` rows of `td.ip-cal__day[role=gridcell]`, 32×32. Roving tabindex: the focused day `tabindex=0`, others `-1`. Selected day `aria-selected="true"` (`control` + `on-control`); today `aria-current="date"` (underlined); days after today `aria-disabled="true"` (`sunken` + `ink-disabled`, no tabindex). Hover `sunken`.
- **Keyboard (calendar):** opening focuses the selected day (or today). ← / → previous / next day; ↑ / ↓ same day previous / next week; Home / End first / last day of the week (row); PgUp / PgDn same day previous / next month (Shift+PgUp / PgDn: year); focus never moves past today (16.11.2026). Enter or Space picks the focused day, writes it as `dd.mm.yyyy`, closes, and returns focus to the calendar key. Esc closes without change and returns focus to the calendar key. Tab cycles ◀, ▶ and the grid inside the dialog.
- **Keyboard (Perioadă and Zi / Săpt.):** each SegmentedControl is `[role=radiogroup][aria-label]` with `[role=radio][aria-checked]` items and a roving tabindex (APG radio group): the checked item `tabindex=0`, the others `-1`, so Tab enters each group once, on its checked item. → / ↓ check the next item, ← / ↑ the previous (wrapping), moving focus with the check; Space checks the focused item; Tab leaves the group. Choosing Interval shows the two DateFields; the preview's tiny inline script demonstrates the keys.
- **States:** default, focus (ring), error (in-flow row), calendar open. Demo at 1180px content width in `preview.html`.
