# SectionTree · Ferme și secțiuni (project addition, SYS10)

The editable section tree of a farm (spec B1, screen S19 farm panel): farm → section or hall → compartment, with add, rename, reorder and retire. CSS: additions.css section 28. Decided by default (user away), to review (D75).

- **Markup:** `div.ip-stree` > `div.ip-list__head` (`h3.ip-cap` "Secțiuni" + `p.ip-note` "Secțiunile cu păsări nu se pot retrage.") > optional Banner > `div.ip-stree__box` > `table.ip-table.ip-stree__t[aria-label]` (the DataTable, unchanged). Columns: Secțiune · Stare · Acțiuni (header hidden text).
  - **Farm row** `tr.is-group.ip-stree__farm` (DataTable group row): name + guide Tag `neutral` ("Ross 308 ouat"; "fără ghid" when none) + note "ouat · 3 hale · 6 compartimente" / "creștere · 6 secțiuni" (· "1 retrasă"). The neutral Tag takes `rule` on the sunken row. No key: farm name, type, guide and retiring the farm are the panel's own fields.
  - **Section / hall** `tr.ip-stree__row.ip-stree--l2`: code (sans 500, like the SectionTile code) + for a hall the note "2 compartimente"; hidden ", hală".
  - **Compartment** `tr.ip-stree__row.ip-stree--l3` (`.is-last` on the last child): deeper indent, a hair `line` rail under the hall code; hidden ", compartiment în H1". One level only (B1: optional parent).
  - **Stare:** Lamp `ok` "cu păsări" / `off` "goală" (state words, like D46's "deschis"/"goală"); a hall has birds when any compartment has. Retired: Tag `neutral` "retrasă", code `ink-secondary`, no key.
  - **Acțiuni:** one IconButton (Lucide ellipsis-vertical, `aria-label` "Acțiuni, H1.1", `aria-haspopup="menu"`, `aria-expanded`, `aria-controls` → the `role=menu` element, as SYS09, FIN13) in a 32px cell; open = `sunken` + `ink`. Menu `div.ip-menu.ip-stree__menu.ip-t-body` (`hidden` while closed) > `div.ip-stree__items[role=menu]` of button menuitems: Redenumește · Mută în sus · Mută în jos · Adaugă compartiment (sections and halls only) · separator · Retrage (`aria-haspopup="dialog"`, as SYS09's Șterge); + `p.ip-note` about Retrage (its effect, or why it is disabled), tied by `aria-describedby` to the Retrage item only, so it is read once, when Retrage gets focus (FIN13; the menu used to point to it too and it was read twice). First/last sibling: the impossible move is `aria-disabled`.
  - **Add row** `tr.ip-stree__add`: ghost Button "+ Adaugă secțiune" (hidden " la Hîrbovăț") at the end of each farm. Compartments come from the hall's menu.
  - **Edit row** `tr.ip-stree__edit` (add or rename, in place of / after the row): visible `label.ip-label` above the field (craft §5: "Compartiment nou în H1", "Cod nou pentru H5-2", so the old code stays in view while renaming) + medium TextField `.ip-input.ip-stree__in` (96px) + Salvează (secondary) + Anulează (ghost); error = the field message `p.ip-err.ip-fieldmsg` (alert icon 14 + text, additions.css section 38; drawn by the helper since FIN13, as S19) under it, `aria-invalid` + `aria-describedby`.
  - **Live region** `p.ip-sr[role=status][aria-live=polite]` after the box (empty until a move): announces Mută în sus / jos, e.g. "H3 mutată în sus: a 2-a din 6 secțiuni la Telița."
- **Rules (B1):** a section with birds can't be retired: Retrage stays in the menu, `aria-disabled`, note "H1.1 are păsări. O poți retrage când e goală."; a hall with active compartments: "H1 are compartimente cu păsări. O poți retrage după ce le retragi pe ele." A section with records but no birds can be retired; its records stay in reports (retire never deletes). Retrage opens a Dialog: "Retrage secțiunea H5-2 de la Telița" · "H5-2 nu mai apare în formulare și pe pagina fermei. Înregistrările ei din Seria 2026 rămân în rapoarte." · Anulează (focus) + destructive "Retrage secțiunea".
- **Errors:** duplicate "Codul H1.2 există deja la Hîrbovăț. Scrie alt cod."; empty "Scrie codul compartimentului." / "…secțiunii."; save failed: the fault Banner with action (additions.css section 49, `role=alert`, copy D143 as on S19) "Compartimentul H1.3 nu s-a salvat: conexiunea s-a întrerupt." / "Verifică conexiunea la internet, apoi apasă Reîncearcă. Codul scris rămâne în rând." + Reîncearcă, which takes the focus; the row stays open with the typed code; load failed: the same Banner, "Secțiunile fermei Hîrbovăț nu s-au încărcat." / "Verifică conexiunea la internet, apoi apasă Reîncearcă." + Reîncearcă.
- **Empty:** farm without sections: off Lamp "fără secțiuni" + "Fermă exemplu nu are încă secțiuni." + the add row; no farms (S19 list): EmptyState "fără ferme" · "Nu există nicio fermă." · primary "Adaugă prima fermă" (B1). Loading: skeleton rows (the farm row keeps `is-group`, sunken), `aria-busy`.
- **Keyboard:** menu keys ↑/↓, Home/End, Enter, Esc returns focus to the key (APG menu button); disabled items (`aria-disabled`) are focusable but inert. Edit row: focus moves to the field on open, Enter = Salvează, Esc = Anulează; afterwards focus returns to that row's Acțiuni key (after adding, to the new row's key). Mută în sus / jos: focus stays on the moved row's key and the live region announces the move. Retrage Dialog: focus starts on Anulează; after retiring, focus goes to the next active row's key (Anulează / Esc returns it to the row's key).
- **States:** key hover `sunken`, pressed `rule`, focus ring; menu item hover/current `sunken`, pressed `rule`, disabled `ink-disabled`. Rows are not targets (no row hover).
- **Layout:** desktop only (S19 lists no phone layout). Fluid from the 440px farm panel (`--panel-w`) to page width; preview at 440 and at page width with both farms.
- **Sources:** codes and hall grouping from `design/data/extracts/farms-sections.json`; guide names illustrative (D22); "cu păsări" / "goală" from the cycle state on 16.11.2026 (Hîrbovăț laying cycle open from 10.02.2026, Telița empty after 28.02.2026, D25). State examples (D39): typed "H1.3", H3 moved up (order H1, H3, H2, …), rename H5-2 → "H5/2" (the workbook's own label), H5-2 retired, failed save. New farm = "Fermă exemplu" (D38).
