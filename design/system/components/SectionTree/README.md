# SectionTree · Ferme și secțiuni (project addition, SYS10)

The editable section tree of a farm (spec B1, screen S19 farm panel): farm → section or hall → compartment, with add, rename, reorder and retire. CSS: additions.css section 28. Decided by default (user away), to review (D75).

- **Markup:** `div.ip-stree` > `div.ip-list__head` (`h3.ip-cap` "Secțiuni" + `p.ip-note` "Secțiunile cu păsări nu se pot retrage.") > optional Banner > `div.ip-stree__box` > `table.ip-table.ip-stree__t[aria-label]` (the DataTable, unchanged). Columns: Secțiune · Stare · Acțiuni (header hidden text).
  - **Farm row** `tr.is-group.ip-stree__farm` (DataTable group row): name + guide Tag `neutral` ("Ross 308 ouat"; "fără ghid" when none) + note "ouat · 3 hale · 6 compartimente" / "creștere · 6 secțiuni" (· "1 retrasă"). The neutral Tag takes `rule` on the sunken row. No key: farm name, type, guide and retiring the farm are the panel's own fields.
  - **Section / hall** `tr.ip-stree__row.ip-stree--l2`: code (sans 500, like the SectionTile code) + for a hall the note "2 compartimente"; hidden ", hală".
  - **Compartment** `tr.ip-stree__row.ip-stree--l3` (`.is-last` on the last child): deeper indent, a hair `line` rail under the hall code; hidden ", compartiment în H5". One level only (B1: optional parent).
  - **Stare:** Lamp `ok` "cu păsări" / `off` "goală" (state words, like D46's "deschis"/"goală"); a hall has birds when any compartment has; an empty hall of a farm whose cycle is still open adds its muted date "goală din 14.11" (Mono date, D158d; H7 since its sale). Retired: Tag `neutral` "retrasă", code `ink-secondary`, no key.
  - **Acțiuni:** one IconButton (Lucide ellipsis-vertical, `aria-label` "Acțiuni, H5.1", `aria-haspopup="menu"`, `aria-expanded`, `aria-controls` → the `role=menu` element, as SYS09, FIN13) in a 32px cell; open = `sunken` + `ink`. Menu `div.ip-menu.ip-stree__menu.ip-t-body` (`hidden` while closed) > `div.ip-stree__items[role=menu]` of button menuitems: Redenumește · Mută în sus · Mută în jos · Adaugă compartiment (sections and halls only) · separator · Retrage (`aria-haspopup="dialog"`, as SYS09's Șterge); + `p.ip-note` about Retrage (its effect, or why it is disabled), tied by `aria-describedby` to the Retrage item only, so it is read once, when Retrage gets focus (FIN13; the menu used to point to it too and it was read twice). First/last sibling: the impossible move is `aria-disabled`.
  - **Add row** `tr.ip-stree__add`: ghost Button "+ Adaugă secțiune" (hidden " la Hîrbovăț") at the end of each farm. Compartments come from the hall's menu.
  - **Edit row** `tr.ip-table__edit.ip-stree__edit` (add or rename, in place of / after the row), one row height (FW03, D150, additions.css §69): medium TextField `.ip-input.ip-stree__in` (96px) at the code's place + Salvează (secondary) + Anulează (ghost) on the row line, all row-h − space-1 (28) with 2px clear above and below (as tall as the rows with their 32px Acțiuni key), on the edit fill (`sunken`). Under it one detail row `tr.ip-table__detail.ip-stree__detail` (td colspan 3, no rule between the two, content at the row's indent): the field's `label.ip-label` ("Compartiment nou în H5", "Cod nou pentru H5-2", so the old code stays in view while renaming; was above the field) and the error = the field message `p.ip-err.ip-fieldmsg` (alert icon 14 + text, section 38); the field `aria-invalid` + `aria-errormessage` + `aria-describedby` → the error.
  - **Live region** `p.ip-sr[role=status][aria-live=polite]` after the box (empty until a move): announces Mută în sus / jos, e.g. "H3 mutată în sus: a 2-a din 6 secțiuni la Telița."
- **Rules (B1):** a section with birds can't be retired: Retrage stays in the menu, `aria-disabled`, note "H5.1 are păsări. O poți retrage când e goală."; a hall with compartments that have birds: "H5 are compartimente cu păsări. O poți retrage după ce le retragi pe ele."; a hall whose compartments are empty but not retired stays blocked too (RF11): "H7 are compartimente active (H7.1, H7.2). O poți retrage după ce le retragi pe ele." A section with records but no birds can be retired; its records stay in reports (retire never deletes). Retrage opens a Dialog: "Retrage secțiunea H5-2 de la Telița" · "H5-2 nu mai apare în formulare și pe pagina fermei. Înregistrările ei din Seria 2026 rămân în rapoarte." · Anulează (focus) + destructive "Retrage secțiunea".
- **Errors:** duplicate "H5.2 există deja în H5. Scrie alt cod, de exemplu H5.3." (as on S19); empty "Scrie codul compartimentului." / "…secțiunii."; save failed: the fault Banner with action (additions.css section 49, `role=alert`, copy D143 as on S19) "Compartimentul H5.3 nu s-a salvat: conexiunea s-a întrerupt." / "Verifică conexiunea la internet, apoi apasă Reîncearcă. Codul scris rămâne în rând." + Reîncearcă, which takes the focus; the row stays open with the typed code; load failed: the same Banner, "Secțiunile fermei Hîrbovăț nu s-au încărcat." / "Verifică conexiunea la internet, apoi apasă Reîncearcă." + Reîncearcă.
- **Empty:** farm without sections: off Lamp "fără secțiuni" + "Fermă exemplu nu are încă secțiuni." + the add row; no farms (S19 list): EmptyState "fără ferme" · "Nu există nicio fermă." · primary "Adaugă prima fermă" (B1). Loading: skeleton rows (the farm row keeps `is-group`, sunken), `aria-busy`.
- **Keyboard:** menu keys ↑/↓, Home/End, Enter, Esc returns focus to the key (APG menu button); disabled items (`aria-disabled`) are focusable but inert. Edit row: focus moves to the field on open, Enter = Salvează, Esc = Anulează; afterwards focus returns to that row's Acțiuni key (after adding, to the new row's key). Mută în sus / jos: focus stays on the moved row's key and the live region announces the move. Retrage Dialog: focus starts on Anulează; after retiring, focus goes to the next active row's key (Anulează / Esc returns it to the row's key).
- **States:** key hover `sunken`, pressed `rule`, focus ring; menu item hover/current `sunken`, pressed `rule`, disabled `ink-disabled`. Rows are not targets (no row hover).
- **Layout:** desktop only (S19 lists no phone layout). Fluid from the 440px farm panel (`--panel-w`) to page width; preview at 440 and at page width with both farms.
- **Sources:** codes, hall grouping and section states through `design/canvas/scripts/realdata.py` (farms-sections, counts, cycles; RF11); guide names illustrative (D22); "cu păsări" / "goală" from the state on 18.11.2026 (Hîrbovăț laying cycle open from 22.02.2026, azi SAPT 59, H7 empty since 14.11.2026; Telița empty after 28.02.2026, D25). State examples (D39): typed "H5.3", duplicate "H5.2", empty code in H7, Retrage blocked on H5.1, H3 moved up (order H1, H3, H2, …), rename H5-2 → "H5/2" (the workbook's own label), H5-2 retired, failed save. New farm = "Fermă exemplu" (D38).
