# StockReadout (project addition, SYS04)

The Readout `--stock` variant: one dark Readout per farm × feed type for S11 › Stoc (spec D4 §1, screens S11 §2), laid in a StockReadoutRow. The only place Readouts repeat inside one section (craft.md, components.md › Readout). CSS: additions.css section 10. Decided by default (user away), to review.

- **Markup:** `ul.ip-readouts[aria-label]` (StockReadoutRow) > `li` > `div.ip-readout.ip-readout--stock[role=group][aria-labelledby]` >
  - `.ip-readout__cap`: farm · feed type (`span` with the id, visible text kept as the name; no `aria-label` on a plain span: the sex the type is for follows as hidden text, `<span class="ip-sr">, pentru găini</span>` / `, pentru cocoși`; write "Breeder&nbsp;2" with a no-break space; the caption stays on one line in the 1136px row) + `ip-rlamp ip-rlamp--ok|warn|off` with its word (the caption uppercases both).
  - `.ip-readout__val`: kg in stock, `readout-lg` (Plex Mono 32/36 500, `readout-ink`), unit `<small> kg</small>`. Whole kg, U+202F thousands, true minus.
  - `dl.ip-readout__kv` (top `readout-line`), three lines, key `dt` Mono 12/16 `readout-muted`, value `dd` Mono 14/20 500 `readout-ink` right-aligned: **zile rămase** ("7,1 zile", one decimal) · **medie/zi 13–15.11** (average of the last 3 complete days, whole kg) · **se termină** (run-out date `dd.mm.yyyy`; "epuizat pe" once below 0).
  - optional `p.ip-readout__sub` (Mono 12/16 `readout-muted`): the reason or detail ("sub pragul de 5 zile", "– fără consum în ultimele 3 zile", "fără ciclu deschis").
- **Figures:** stock = Σ deliveries − Σ consumption of that type at that farm (data-model › Feed stock), confirmed rows to date. Days left = stock ÷ average consumption over the last 3 complete days (16.11 is still being entered, so 13–15.11). Run-out date = today + days left (floor).
- **States (Lamp vocabulary, D42):**
  - `ok` **în normă**: ≥ 5 days. Hîrbovăț · Breeder 2: 28 252 kg, 7,1 zile, 3 976 kg/zi, se termină 23.11.2026.
  - `warn` **abatere**: < 5 days (D19); sub-line "sub pragul de 5 zile". Hîrbovăț · Cocoși: 1 650 kg, 3,9 zile, 419 kg/zi, 19.11.2026.
  - stock below 0 (D40: a warning, never a refusal; D50 wording): `warn` lamp **abatere** (D42 vocabulary), value with a true minus, "0,0 zile", "epuizat pe 16.11.2026", sub-lines "stoc sub 0 · verifică livrările" and "consumul depășește livrările". Preview figure −1 240 kg = the spec C2 example, a state example only (D39).
  - `off` **oprit**, no recent consumption: kg shown, "zile rămase –", "medie/zi 0 kg", "se termină –", sub-line "– fără consum în ultimele 3 zile". Preview: "Fermă exemplu · Starter" 8 000 kg (state example, D39).
  - `off` **oprit**, farm without an open cycle (`ip-readout--off`): one readout per farm (no feed type), value "–" in `readout-muted`, no kv lines, sub-lines "fără ciclu deschis" and "ultimul ciclu: Seria 2026, închis pe 28.02.2026". Telița: never a negative stock as real (the workbook's −716 kg Sold of 26.02.2026 stays in extract meta, D35).
- **StockReadoutRow:** `.ip-readouts` grid, `auto-fill` columns of ≥ 240px (`--space-12` × 5): 4 per row in the 1136px desktop content, so 2–3 readouts keep the same width; one column on phone (390, stacked). Order: open farms first, then by days left ascending is the screen's call; the preview keeps farm order (Hîrbovăț Breeder 2, Cocoși, then Telița). An `ip-note` under the row names the formula, window and threshold.
- **No icon:** `rec-feed` (#7F5C00) is 2,92:1 on the `readout` ground (under 3:1 for a graphic), and a light `rec-feed-bg` tile would break the dark panel. The caption word names the feed type; the package tile stays for light-surface rows (alerts, deliveries).
- **Tokens:** `readout`, `readout-ink` (15,2:1), `readout-muted` (6,81:1), `readout-line` (decorative divider), `readout-ok/warn` + the SYS01 off ring, `radius-md`, `space-1/2/3`. No new colours.
- **A11y:** each readout is a labelled group; lamps carry their word; no targets inside (a screen may wrap the readout in a link to the type's deliveries; focus then uses the `readout-ok` ring from additions.css § 5).
- **Sources:** `sample-hirbovat-2026.json` › `stock_today`, `feed_by_type_daily` (13–15.11: 3 977,4 / 3 975,7 / 3 974,6 and 419,1 / 419,1 / 418,3 kg) — sample (D27); `cycles.json` (Telița closed 28.02.2026, real); `feed-daily-telita.json` meta (−716 kg, not shown).
