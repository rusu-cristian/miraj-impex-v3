# EventRow · actions (project addition, SYS09)

An EventRow whose record the user may change: per-row Editează / Șterge / Corectează, the "corectat" / "modificat de …" marks, locked and deleted rows. For S15 Introdus azi (spec C8), S16 Corectează entry points (E1) and every event log (S4, S5). CSS: additions.css section 26. Decided by default (user away), to review (SYS09 decisions A–D).

- **Markup:** `ul.ip-list.ip-list--act[aria-label]` (a size container, `overflow:visible`) > `li.ip-ev.ip-ev--act`: RecordTile (`aria-hidden`) · `.ip-ev__main` > `.ip-ev__title` (Type · section · ♀/♂ figures, Mono figures never split from their unit; a "♀ și ♂" pair in `.ip-ev__sexes`, nowrap) + `.ip-ev__meta` (time or `dd.mm.yyyy · SAPT 59` · author · detail) + optional `.ip-ev__mod` · action slot.
- **Who gets which key (spec C8, E1, D07):**
  - Author, same day until 23:59: **Editează** (`a.ip-btn--ghost`, opens the form in edit mode) + **Șterge** (`button`, `aria-haspopup="dialog"`, Dialog with focus on Anulează). The window is said once in the list head ("poți modifica sau șterge până la 23:59"), not per row: `div.ip-list__head` > `h2.ip-cap` "Introdus azi" + `p.ip-note` "18.11.2026 · poți modifica sau șterge până la 23:59" (wraps under the title when narrow).
  - Manager / owner on a past day: **Corectează** (link to S16: changed values, reason ≤ 200 characters, effect preview, never-below-0 check) + **Șterge** (reason required + Dialog). Default for others' entries of today: also Corectează (decision B).
  - Vet on a past own entry: **locked**: `.ip-ev__lock` holds Tag `neutral` "blocat" (EventRow's locked rows); the meta says why: "zi trecută · o corectează managerul".
  - Vet on someone else's entry (past or today): no action slot, like a viewer (D71); "blocat" only on the vet's own past entries.
  - Viewer (Observator): no action slot; marks stay.
- **Layouts (container width):** ≥ 480px `.ip-ev__acts`: ghost keys at `control-h`, 12px side padding, 4px apart; every key has the record in hidden text ("Editează<span class=ip-sr> Mortalitate de azi</span>"). < 480px `.ip-ev__more`: one `ip-iconbtn--touch` (48, Lucide ellipsis-vertical, `aria-label="Acțiuni, Mortalitate de azi"`, `aria-haspopup="menu"`, `aria-expanded`, `aria-controls`) opening `div.ip-menu.ip-ev__menu` (rendered `hidden` while closed, so `aria-controls` always resolves), right-aligned under the key: `div.ip-ev__items[role=menu][aria-describedby → note]` holding only `role=menuitem` items (48px, `tabindex=-1`) + a sibling `p.ip-note[id]` outside the menu (the 23:59 window or the reason rule). The unused layout is `display:none`. Menu keys: ↑/↓, Home/End, Enter, Esc returns focus to the key (APG menu button).
- **Marks:** corrected record (E1): `.ip-ev__mod` = Tag `neutral` **corectat** + `a.ip-link` "modificat de Ion Rusu · 18.11.2026, 10:12" → Istoric modificări filtered to this record (E2 entry point); for roles without Istoric (vet, observer) the same words as plain text, no link (D104/D105, D178); hit area 24px desktop, 48px phone (padding + negative margin, text wraps as text; the Mono date-time never splits). Same-day edit by the author: "modificat la 09:52" in the meta (`.ip-ev__edited`), no Tag, no link (decision A).
- **States:** key hover `sunken`, pressed `rule`, focus ring (system); phone key the same; **disabled with reason** — the 23:59 window closes while the page is open: keys stay in place and focusable: Editează `a[role=link][tabindex=0][aria-disabled=true]` (no href), Șterge `button[aria-disabled=true]`, both `aria-describedby` → `.ip-ev__why` in the meta ("timpul de modificare s-a încheiat la 23:59 · o corectează managerul"); in the phone menu the items are `aria-disabled` (`ink-disabled`) with `aria-describedby` → the note, which says why; **locked** (above); **deleted** `.ip-ev--deleted`: tile drops to steel (`sunken` + `ink-secondary`, type kept by icon and word), title `ink-secondary` with the figures in `<del>`, hidden "(șters)", Tag "șters" + link "șters de … · dd.mm.yyyy, hh:mm"; no keys. Where deleted rows show: decision D (default: only where history is shown).
- **A11y:** the row is not a target (no row hover, also not when its "modificat de" / "șters de" link is hovered: `.ip-ev--act` is excluded from the EventRow `:has(a:hover)` rule); keys ≥ 32px desktop, 48px phone; every key name includes the record; lamps/Tags carry words; locked and disabled reasons are text, not colour.
