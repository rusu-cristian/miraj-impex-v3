# Dialog

Confirms destructive and cycle-changing actions.

- **Style:** `panel`, radius `radius-lg`, `shadow-overlay`, on `scrim`.
- **Title:** names the action and the object.
- **Fields:** a reason where required.
- **Focus:** starts on Anulează.
- **Placement (FIN04, additions.css §35/§50):** desktop `ip-scrim ip-scrim--page` over the whole page and any open SidePanel, phone `ip-scrim--phone` over the screen; Dialog centred both ways; page and panel under it `inert`; body `p.ip-dialog__note`, keys `div.ip-dialog__keys` (phone `--stack`), Anulează first.
