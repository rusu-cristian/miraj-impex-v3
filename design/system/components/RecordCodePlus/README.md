# RecordCode additions · Corecție + cycle marks (project addition, SYS06)

CSS: additions.css section 17. Preview: Telița registry rows (real) + one Hîrbovăț sample edit + one D39 state row.

- **Corecție (adjustment, BIRD_EVENT type, D01):** a count change with no other cause (e.g. Telița H5-1 ♂ +11 on 21.02.2026, an unpaired "Corectie"). Class `ip-rec--adjust`: icon `ink-secondary` on `sunken` (steel, not a new hue, not a status colour). Contrast: 6,46:1 on its `sunken` tint, 7,11 ground, 7,86 panel, 8,52 raised, 5,98 on `rule` (pressed). Icon: Lucide "pencil-line" (paths in preview.html). Works for RecordTile, RecordChip (FilterBar order: after Eroare sexare) and DataTable headers. Close pair: Mortalitate (dark grey skull) — told apart by icon and word, like the other close pairs.
- **Corecție ≠ an edited record:** changing a past record (D07, AUDIT_LOG) keeps the record's own type and tile and adds the neutral Tag "corectat" (D41), with "modificat dd.mm.yyyy: old → new" in the meta.
- **Cycle marks on EventRows (ciclu nou / ciclu închis):** `span.ip-cmark.ip-cmark--start|--end` in `.ip-ev__meta`, CycleTrack vocabulary: the 3×12 mark bar (`--ip-mark-w`) beside a mini cycle block, open block (`raised` + 1,5px `ink`) for a start, closed block (`panel` + `ink-muted` edge, D38) for an end; bar before the block = start, after = end. Bar colour = the record that opened/closed the cycle, as on the track: `.place` rec-placement, `.xfer` rec-transfer, `.sale` rec-sale, `.ded` = no bar but `svg.ded` (viewBox 0 0 3 12, one 1,5px `ink-secondary` line dashed 3 3), the CycleTrack inferred-start line (început dedus, D55), so it never reads as the solid bar, none = `ink` (Începe ciclu nou, golire). Glyph `aria-hidden`; the word ("ciclu nou", "ciclu închis · Telița") is the accessible text. Never a Tag or Lamp (not a status).
- **Cycle-only rows** (Începe ciclu nou, D17; ciclu încheiat prin golire, D54): lead with `span.ip-tile.ip-tile--cycle` (hollow: `raised` + 1px `line`, glyph `ink`), since no record type applies; title "Ciclu nou · farm · …" / "Ciclu închis · farm · series · prin golire".
- **Demo table:** the colour/contrast table sits in `div.ip-tablescroll` (DataTable phone rule, additions.css › 16), so it scrolls in its own box at 390.
