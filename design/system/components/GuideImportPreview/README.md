# GuideImportPreview · Ghiduri import (project addition, SYS11)

The preview of an imported guide before it is saved (spec B2, screen S20 import panel): the rows read from a pasted table or an .xlsx/.csv file, refused rows marked in the row and in the cell, a summary of what blocks saving and what only informs. CSS: additions.css section 29. Decided by default (user away), to review.

- **Markup:** `section.ip-gimp[aria-label]` > source line > fault Banner (refused rows) > info Banner (doesn't block) > filter bar > scroll box with the DataTable > foot > live region.
  - **Source line** `div.ip-gimp__src`: `span.ip-gimp__file` (name in 500, e.g. "Ross 308 creștere.xlsx" or "Tabel lipit", + `ip-note` "fișier .xlsx · tip creștere" / "din clipboard · tip ouat") · `p.ip-gimp__counts#…-sum` "51 rânduri citite · 48 valide · 3 refuzate" (figures Mono) · ghost key "Alege alt fișier" / "Lipește alt tabel" / while reading "Anulează citirea"; no key on an empty file (its EmptyState holds "Alege alt fișier", S20P).
  - **Refused rows** (FileDrop: "row errors show in a fault Banner"): `div.ip-banner--fault` with "3 rânduri refuzate. Corectează-le în fișier și încarcă-l din nou; până atunci ghidul nu se poate salva." + `ul.ip-gimp__errs` of links "Rândul 7 · SAPT 3 ♂: greutatea „#REF!” nu e număr." pointing at the refused cell.
  - **Doesn't block** `div.ip-banner--info` "Nu blochează salvarea." + what will show as `–` fără date în ghid (blank cells by week and row, guide columns the file doesn't have). All valid: ok Banner "Toate cele 50 de rânduri sunt valide."
  - **Filter** `div.ip-gimp__bar`: caption "Rânduri" + SegmentedControl of toggle buttons (`aria-pressed`) "Toate 51 · Refuzate 3"; shown only when rows are refused.
  - **Table** `div.ip-gimp__box[tabindex=0][role=region][aria-label]` (max 12 rows + sticky header, then it scrolls) > `table.ip-table.ip-gimp__t[aria-describedby=…-sum]`, the DataTable unchanged: one row per file row (week × sex). Columns: Rând (file line, header = line 1, `ink-muted`) · Vârstă (ouat only) · SAPT · Sex (♀/♂ sign in its record colour + hidden "găini"/"cocoși") · the guide columns the file has (Hrană g, Greutate g, Ouat % …; figures Mono, coloured by the row's sex) · Verificare.
  - **Refused row** `tr.is-refused`: the cell at fault `td.ip-gimp__bad[tabindex=-1][aria-invalid=true][aria-describedby=…-why]` shows the value exactly as read (fault text on `fault-bg`, hair fault edge; an empty cell carries hidden "gol"); Verificare = Lamp fault "refuzat" + the reason `span#…-why` naming the value and the fix. Cell-level for a bad value or a missing sex; a duplicate marks SAPT + Sex.
  - **Partial guide** (B2): a blank cell shows `–` (`ink-muted`, hidden "fără date în ghid"), Verificare "fără date în ghid: greutatea" as a guide line (D29, never a Lamp). ♂ Ouat % = `–` with hidden "nu se aplică la cocoși", no note.
  - **Foot** `div.ip-gimp__foot`: primary "Salvează ghidul" + ghost "Anulează" + `p.ip-note#…-foot` ("Se salvează 50 de rânduri în ghidul Ross 308 creștere."). With refused rows, while reading, or with no rows: `aria-disabled="true"` + `.is-disabled`, `aria-describedby` → the note ("3 rânduri refuzate: corectează fișierul și încarcă-l din nou.").
  - **Live region** `p.ip-sr[role=status][aria-live=polite]`: "Fișier citit: 51 de rânduri, 3 refuzate." when reading ends.
- **Rules (B2):** refused (block saving): duplicate week + sex ("SAPT 4 ♀ e deja pe rândul 8. Păstrează un singur rând."), a value that isn't a number ("Greutatea „#REF!” nu e număr. Scrie greutatea în grame."), missing or unknown sex ("Lipsește sexul. Scrie G (♀) sau C (♂)."; G/C, F/M and ♀/♂ are read). Don't block: blank cells and guide columns absent from the file (they show `–` fără date în ghid). Ouat guides are read by age week; SAPT = vârstă − 18 (D26), shown beside it; creștere: SAPT = vârstă, one column.
- **Keyboard:** Tab order: source key → error links in the fault Banner → filter buttons → table box (focusable region, arrows scroll) → Salvează ghidul (focusable while `aria-disabled`, reads its reason) → Anulează. An error link moves focus to the refused cell (`tabindex=-1`, focus ring drawn inside the cell), which reads its value, "invalid" and the reason; the box scrolls it into view (with filter Toate). Tab from there goes on to Salvează; Shift+Tab back to the box. Toate / Refuzate are toggle buttons (Space/Enter); switching keeps focus on the button. Reading ends: focus stays on the source key, the live region announces the counts, the table's `aria-describedby` points at the counts line.
- **States:** se citește (source line "Se citește fișierul.", six additions §42 skeleton rows `tr.ip-table__skel` with each bar as wide as its column's figures in `ch` (§42 `ip-skel--ch1…4`, FIN11) and at their edge, no hidden text row, live region "Se citește <fișier>.", `aria-busy`, Salvează off; S20P); toate valide (ok + info Banners, Salvează on); rânduri refuzate (fault Banner with links, cells marked, filter, Salvează off); filtru Refuzate; focus on a refused cell; format greșit (.pdf: fault Banner "Ross 308 creștere.pdf nu se poate citi. Încarcă un fișier .xlsx sau .csv, sau lipește tabelul." + the FileDrop again); necitibil (no SAPT / Sex header: "… nu are antetul cu coloanele SAPT și Sex. Pune pe primul rând numele coloanelor de sub chenar și încarcă fișierul din nou."); gol (header only: EmptyState off Lamp "fără date" + "Alege alt fișier", the only key; foot note "Scrie rândurile ghidului sub antet sau alege alt fișier."). Figures: percentages keep one decimal (89,0), as the guide detail; running text writes "sapt. 24–25", labels and Mono cells keep SAPT. FileDrop = the paste target (additions §43, `ip-drop--paste`) (S20P). Hover/pressed/disabled from additions.css; segment hover → `ink`.
- **Layout:** desktop only (owner setup; S20 lists no phone layout). Needs ≥ 672px (2 + 2 guide columns plus the reasons); preview at 672.
- **Sources:** figures from `design/data/extracts/guide-growth.json` (creștere, SAPT 1–25, 50 rows, weight to SAPT 23) and `guide-laying.json` (ouat, vârsta 19–65, 94 rows; ouat % ♀ illustrative, D29). Guide and file names illustrative (D22). State examples (D39): row 7 weight "#REF!" (guide 550), row 10 a second SAPT 4 ♀, row 12 without sex (SAPT 5 ♂); the .pdf, header-less and empty files. Builder/render: `design/system/scripts/sys11_build.py`, `sys11_render.py`.
