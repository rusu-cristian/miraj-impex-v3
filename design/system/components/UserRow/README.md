# UserRow · Utilizatori list (project addition, SYS12)

The users list of S22 Utilizatori (spec A2, owner only): one DataTable row per user with name, login, role, farms, last sign-in and whether the account is active, and one row menu for Editează, Resetează parola and Dezactivează / Reactivează. The password shown after a reset or a new account is `OneTimePassword/`. CSS: additions.css section 30. Decided by default (user away), to review.

- **Markup:** `section.ip-users[aria-labelledby]` > list head > `div.ip-users__box` > `table.ip-table.ip-users__t` (the DataTable unchanged) > `tr.ip-user` rows > live region.
  - **List head** `div.ip-list__head`: caption `h3.ip-cap` "Utilizatori" · `p.ip-note#…-sum` "5 utilizatori · 4 activi · 1 dezactivat" (figures Mono; the table's `aria-describedby`) · primary "Adaugă utilizator" (plus icon, `aria-haspopup="dialog"`, opens the add panel). The page's one primary key lives here, so the S22 PageHeader carries only the title.
  - **Columns:** Nume (`span.ip-user__name`: name in 500 `ink`; your own row adds `ip-note` "(tu)") · Login (Mono, `[a-z0-9.]`) · Rol (plain text: Proprietar · Manager · Veterinar · Observator, D48) · Ferme (names joined by ", "; the owner has every farm: "toate fermele" in `ink-secondary`) · Ultima intrare (Mono `dd.mm.yyyy, hh:mm`; never signed in: `– încă n-a intrat` in Sans `ink-muted`) · Stare (Lamp ok "activ" / off "dezactivat") · action column (`th` holds a hidden "Acțiuni").
  - **Row key** `td.ip-users__act` > IconButton (ellipsis-vertical) `aria-label="Acțiuni pentru Ion Rusu"`, `aria-haspopup="menu"`, `aria-expanded`, `aria-controls` → `div.ip-menu.ip-users__menu` (`hidden` while closed; `--up` on the last two rows so it opens upward inside the list) > `div.ip-users__items[role=menu][aria-label]` of `button[role=menuitem]` + `div.ip-users__sep[role=separator]` before the account item + `p.ip-note` (reason for a disabled item, tied by `aria-describedby` on the menu and on that item). Open key = `sunken` + `ink`. The SectionTree menu pattern (SYS10), unchanged.
  - **Menu items:** active user: Editează (opens the user panel: role and farms) · Resetează parola (`aria-haspopup="dialog"`) · Dezactivează (`aria-haspopup="dialog"`). Deactivated user: Editează · Resetează parola `aria-disabled` ("Contul e dezactivat. Reactivează-l ca să-i dai o parolă nouă.") · Reactivează. Your own row: Dezactivează `aria-disabled` ("Nu îți poți dezactiva propriul cont.").
- **Rules (A2):** users are never deleted; deactivating keeps their entries ("Datele introduse de el rămân.") and can be undone with Reactivează. You can't deactivate yourself, and at least one active owner must exist (with self-deactivation blocked the list can't lose its last owner; changing your own role away from Proprietar while you are the only active owner is blocked in the user panel, not here). Farms: at least one unless the role is Proprietar (panel). Order: active users by role (Proprietar, Manager, Veterinar, Observator), then name; deactivated users last, text `ink-secondary`.
- **Dialogs** (Dialog unchanged, `div.ip-users__dfoot` right-aligned keys, focus starts on Anulează):
  - "Resetează parola lui Ion Rusu": "Parola de acum nu va mai merge. Noua parolă temporară se arată o singură dată, aici." · Anulează + primary "Resetează parola" → the same dialog turns into the OneTimePassword. Failed: fault Banner `#…-why` "Parola nu s-a resetat; cea veche merge în continuare. Verifică conexiunea și apasă Reîncearcă." (no role) · Anulează + primary Reîncearcă; focus moves to Reîncearcă (the next step; nothing is lost by retrying), Esc = Anulează. The dialog and Reîncearcă both carry `aria-describedby` → the Banner, so the reason is read with the key.
  - "Dezactivează contul lui Petrea": "Petrea nu va mai putea intra. Datele introduse de el rămân. Poți reactiva contul oricând." · Anulează + destructive "Dezactivează" → Toast "Contul lui Petrea e dezactivat."; the row moves last with the off Lamp.
  - Reactivează: no dialog (nothing is lost); Toast "Contul lui Petrea e activ din nou."; the row moves back among the active ones.
- **Keyboard:** Tab reaches "Adaugă utilizator", then one Acțiuni key per row (rows and cells are not targets). Menu (APG menu button): Enter / Space / ↓ open with focus on the first item, ↑ opens on the last; ↑/↓ move, Home/End, type-ahead by first letter; Enter / Space activate; Esc or Tab close and return focus to the key. Disabled items stay focusable and inert, their reason is read through `aria-describedby`. A dialog item opens its Dialog (focus on Anulează, Tab trapped, Esc = Anulează; when the reset fails, focus moves to Reîncearcă and Esc stays Anulează: focus moves inside the open dialog, so the dialog's description is not re-read and Reîncearcă's own `aria-describedby` → fault Banner makes it "Reîncearcă, buton, Parola nu s-a resetat; …"); on close focus returns to that row's Acțiuni key. After Dezactivează / Reactivează the row moves and focus follows its key; the Toast (`role=status`) announces the change. Load failed: the list's live region (`p.ip-sr[role=status]`) says "Utilizatorii nu s-au încărcat."; the fault Banner has no role (one announcement, not two); Tab reaches Reîncearcă after Adaugă utilizator. After a new user is saved, focus lands on the new row's key once the password dialog closes.
- **States:** default; menu open (keyboard-current item `is-active`); own row (Dezactivează disabled + reason); deactivated row (off Lamp, `ink-secondary`, Reactivează, Resetează parola disabled + reason); never signed in (`– încă n-a intrat`); empty (A2: your row + `tr.ip-users__empty` with off Lamp "doar tu" and "Doar tu ai acces. Adaugă primul utilizator."; the head key is the next step); loading (skeleton rows, `aria-busy`, "Se încarcă."); load failed (fault Banner "Utilizatorii nu s-au încărcat. Verifică conexiunea și apasă Reîncearcă." + secondary Reîncearcă, no table; the status region announces "Utilizatorii nu s-au încărcat."); dialog states above. Hover / pressed / disabled from additions.css section 1.
- **Layout:** desktop only (owner setup; S22 lists no phone layout). Preview at 1056px (the S22 content width at 1440); seven columns fit on one 32px row from about 880px.

State examples (D39): the rows "Proprietar exemplu" and "Observator exemplu", the other logins, every last sign-in time and Petrea's deactivated account.
