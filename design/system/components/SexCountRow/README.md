# SexCountRow (project addition, SYS07)

One row per section with ♀ and ♂ counts, for S10 Vânzare (spec C4), S18 Serie nouă placement (spec B3) and S9 Transfer (spec C3). Built from CountInput, SexCount, Checkbox, IconButton, SectionSelect and Button ghost; CSS in additions.css §18. bundle.css is unchanged.

- **Markup:** `section.ip-panel.ip-sexrows[aria-labelledby]` > `.ip-sexrows__head` (`h4.ip-cap` "Păsări vândute" / "Populare pe secțiuni" + `ip-note` farm · date) > (wide only) `.ip-sexrows__cols[aria-hidden]` > `ol.ip-sexrows__list` > `li.ip-sexrow` … > optional ghost key `button.ip-btn.ip-btn--ghost.ip-sexrows__add` "Adaugă secțiune" (plus icon) > `.ip-sexrows__total`.
- **Row:** `.ip-sexrow__head` (code `span.ip-sexrow__code` 16/22, or SectionSelect when the user adds the row · `.ip-sexrow__alive` "în viață" + SexCount pair where birds go out: Vânzare, Transfer · remove `button.ip-iconbtn.ip-sexrow__rm[aria-label="Elimină H1"]` on user-added rows only, Lucide "x") > ♀ field `.ip-field.is-hen` > ♂ field `.ip-field.is-rooster` > message `p.ip-err.ip-sexrow__msg` > Checkbox `label.ip-check.ip-sexrow__all` "Toate" (Vânzare, Transfer).
- **CountInput:** `span.ip-input.ip-count.ip-count--hen|rooster` (sex bar) > `input[inputmode=numeric][pattern="[0-9]*"][placeholder="–"]`. Empty "–" = null, not 0. Label `label.ip-label.ip-sexrow__lbl[for]`: hidden section prefix ("H1.1, "), visible ♀/♂ (`aria-hidden`) and hidden "găini"/"cocoși". Inputs are described by the row's "în viață" and by their message. Digits only in the value; U+202F grouping on blur (as EntryCardPlus). Enter moves to the next CountInput. Phone CountInput 56; desktop `ip-count--md`.
- **Toate:** a real hidden checkbox (`input.ip-sr`) + hidden suffix " din H1.1", on `label.ip-check.ip-sexrow__all[id="all-…"]`. Checked fills ♀ and ♂ with everything alive in that section (on the chosen day) and makes both inputs native `readonly` (`sunken`, sex bar kept, value `ink`; no `aria-readonly`), and the Toate label's id joins their `aria-describedby` ("în viață" · "Toate din H1.1"), so screen readers hear why they can't be typed in; unchecking removes it and restores the draft. Only where birds leave a section (Vânzare, Transfer Din); not in placement.
- **SectionSelect (user-added rows):** the section 53 Select (FIN10, D130; the preview since FIN13): `div.ip-field.ip-sexrow__sel` > label + `div.ip-select` > desktop: APG select-only combobox `div.ip-input.ip-select__btn[role=combobox][tabindex=0]` (`aria-expanded`, `aria-controls`, `aria-activedescendant`, label "Secțiune"; value `span.ip-select__val > b`, placeholder `is-empty` "Alege") + `ul.ip-menu.ip-select__menu[role=listbox]` of `li.ip-select__opt` (check slot `ip-select__chk`, `ip-select__txt > ip-select__top` code + note): group caption "Telița · creștere", options with note "goală" (empty section), sections already in the list `aria-disabled` with the reason "în listă" (as "sursa"). Placeholder "Alege". Phone: not a listbox combobox; the combobox has `aria-haspopup="dialog"`, `aria-controls` only while open and no `aria-activedescendant`, and opens the modal BottomSheet (additions.css §33; components.md › Additions › S9P): 48 rows, reason words, inert page behind, focus on the sheet's listbox with `aria-activedescendant`, Tab trapped, Esc / Închide back to the combobox. Farm is chosen once above the list; rows show the section code.
- **Missing sex:** a sex left "–" is not required (placement H1 ♀ 14 080 · ♂ –). A row needs at least one count to save ("H3: introdu ♀ sau ♂, sau elimină rândul.").
- **Refusal (count above alive):** `is-error` + `aria-invalid` on the CountInput, message naming section, number, alive, day and fix: "H3.1: 500 depășește cei 437 cocoși în viață pe 16.11.2026. Introdu cel mult 437." Save disabled; the screen's SaveBar carries Lamp `fault` "refuzat" + "H3.1 ♂ 500".
- **Duplicate section:** combobox `is-error` + `aria-invalid`, message "H2 e deja în listă. Alege altă secțiune sau elimină rândul." (guard for restored drafts or list changes; the menu already disables sections in the list). Save disabled.
- **Totals:** caption ("Total vânzare" / "Total populare") + sub-line (filled rows: "2 din 6 secțiuni · în viață ♀ 25 252 · ♂ 2 685"; "3 secțiuni"; "4 rânduri · H2 de două ori") + SexCount pair at `readout` size (20/24, 500), the ♀ · ♂ sums of what is typed (empty = not counted; no figure at all in a sex = "–"). Phone: one SexCount pair, right edge. Desktop (`--wide`): the same markup, the pair's ♀ sum sits in grid area `f` and the ♂ sum in area `m`, each right-aligned under its input column (the "·" is hidden). Not a live region.
- **Layouts:** phone by default: head line (code + alive, or Secțiune field + remove 48), then ♀ and ♂ inputs side by side (56), then Toate, rows split by `rule`, totals under a `line-strong` edge. `ip-sexrows--wide` (desktop markup: 32px controls): one line per row with a column head (Secțiune · În viață · ♀ găini · ♂ cocoși), visible field labels move to the head (kept for screen readers), message on a second grid line, ♀ total under the ♀ column and ♂ total under the ♂ column, right-aligned. Applied by a container query only when the list is ≥ 640px wide, otherwise stacked. `ip-sexrows--add` (user-added rows): columns Secțiune (192) · ♀ · ♂ · · remove. `ip-sexrows--pick` (Transfer Din): areas `sec alive f m all`, columns Din (`space-12` × 4 = 192) · În viață · ♀ · ♂ · Toate; on phone the Din select takes the first line and "în viață" sits under it, left.
- **Transfer (S9), `ip-sexrows--pick`:** one row for the Din section: SectionSelect labelled "Din" (value "Hîrbovăț › H1.1"; menu grouped by farm with type caption, each option with its alive ♀ · ♂ as in SectionSelect) · "în viață" SexCount · ♀ / ♂ CountInputs · Toate. No remove key, no "Adaugă secțiune", no totals line (one row; the screen's SaveBar carries the summary). The În section is a separate SectionSelect above. Panel caption "Păsări transferate" + date.
- **Tokens:** existing only (`panel`, `line`, `line-strong`, `rule`, `sunken`, `ink*`, `rec-hen/rooster`, `fault`, `control`, `space-*`, `radius-*`, `control-h`); vars from earlier sections (`--ip-fs-heading`, `--ip-fs-small`, `--ip-fs-figure`, `--ip-hair`); new `--ip-sexrow-in`, `--ip-sexrow-cols`, `--ip-sexrow-areas` (from space tokens).
- **Preview figures:** Hîrbovăț alive 16.11.2026 from the sample (D27, counts-latest); Telița placement 07.10.2025 real (H1 ♀ 14 080, H2 ♀ 14 000, H5-1 ♂ 3 510). Typed state examples (D39): H1.2 ♀ 2 000, H3.1 ♂ 500, H2 added twice. Transfer from Hîrbovăț › H1.1 is a D39 state example (the extracts only hold the Telița → Hîrbovăț transfers of February 2026), with H1.1 alive ♀ 4 280 · ♂ 429 from counts-latest; typed ♀ 1 000 · ♂ 100 (phone) and Toate (desktop); footnoted in the preview.
- **"Toate secțiunile" key (Vânzare only; additions.css section 34, S10P, D85):** `button.ip-btn.ip-btn--ghost.ip-sexrows__allkey[aria-pressed]` right after `.ip-sexrows__head`, before the list (`ip-btn--touch` on phone): the system Checkbox box `span.ip-check__box[aria-hidden]` (Lucide check when "true", Lucide minus when "mixed", empty when "false") + "Toate secțiunile" + hidden " din Hîrbovăț". "true" = every row has Toate on, "mixed" = some, "false" = none; from "false"/"mixed" it turns every row on, from "true" every row off (rows get their drafts back). The key pulls left by its padding and its hair border, so its box sits on the rows' Toate boxes (phone; FIN13), and a `rule` splits it from the first row. Hidden on the saved form; not on Transfer or placement. The preview draws "mixed" (H1.1 Toate on, the rest off), the state no S10 board shows in view (D60, FIN12).
