# EntryCard additions (project addition, SYS05)

Extends EntryCard (one section in the Zilnic form, spec C1, screen S6) in the system's language. Markup classes below; CSS in additions.css §12. bundle.css EntryCard/CountInput/Select/Checkbox are unchanged.

- **Markup:** `section.ip-panel.ip-entry[aria-labelledby]` > `.ip-entry__head` (`h4.ip-entry__code` "H1.1", status Tag on the right, `.ip-entry__alive` "în viață" + SexCount pair = birds alive at the **start** of the chosen day, the bound every count is checked against) > `.ip-entry__grid` > `.ip-entry__more` (ghost key "Mai mult · Eroare sexare", `aria-expanded` + `aria-controls` = the id of its panel `div.ip-entry__panel[hidden]`, which follows the key) > `.ip-entry__foot` (Checkbox "Fără pierderi azi", or saved meta + Editează).
- **Grid:** one column per sex present, ♀ left (`.is-hen`), ♂ right (`.is-rooster`); rows Mortalitate, Sacrificare, Motiv. A section with one sex uses `.ip-entry__grid--one` (Mortalitate | Sacrificare side by side). Fields: `div.ip-field` > `label.ip-label[for]` (record icon in its colour: skull `rec-mortality`, ban `rec-cull`; sex sign `aria-hidden` + hidden word "găini"/"cocoși") > `span.ip-input.ip-count.ip-count--hen|rooster` > `input[inputmode=numeric][pattern="[0-9]*"][placeholder="–"]`. Empty = "–" (null, not 0). Valoarea câmpului e doar cifre; gruparea cu spațiu îngust se aplică la ieșirea din câmp (blur: "4370" → "4 370", focus: back to "4370"), so a prefilled or saved figure never fails `pattern`. The static preview shows the grouped text, so there (only) inputs holding a grouped value use the demo `pattern="[0-9 &#8239;]*"`, noted under the preview. Phone: CountInput 56, Select 48, keys 48; desktop uses `ip-count--md`, plain controls.
- **Yesterday hint** (under each sex's Mortalitate, `.ip-entry__hint`, in the input's `aria-describedby`): "ieri ♀ 3 · media 7 zile 1,0": words `ink-muted` 12/16, figures Plex Mono, sign in `rec-hen`/`rec-rooster`; segments never break inside, a 157px column wraps at the dot. ieri = mortality of the day before; media = mean daily mortality of the 7 days before the chosen day, one decimal.
- **Warning (saveable):** Mortalitate > 3 × the section's 7-day mean for that sex (D19). CountInput `is-warn`, Tag `warn` "abatere", full-row `p.ip-warnline.ip-entry__msg[role=status]`: "H1.1: 4 găini moarte, de peste 3 ori media pe 7 zile (1,0). Verifică numărătoarea; poți salva." Salvează stays enabled; SaveBar shows Lamp `warn` "abatere" + "H1.1 ♀ 4 · poți salva". Rule taken literally: a mean of 0,0 warns on any death.
- **Refusal (save disabled):** Mortalitate + Sacrificare + Eroare sexare of one sex > birds alive at the start of the day. CountInput `is-error` + `aria-invalid`, Tag `fault` "refuzat", full-row `p.ip-err.ip-entry__msg`: "H1.2: 4 370 depășește cei 437 cocoși în viață pe 16.11.2026. Introdu cel mult 437." (section, number, day, fix). SaveBar Lamp `fault` "refuzat" + "H1.2 ♂ 4 370 · corectează ca să salvezi", Salvează `disabled`.
- **Sacrificare reason:** when a sex's Sacrificare > 0, a required Select "Motiv ♀|♂" appears in that sex's column under it: `span.ip-input.ip-input--touch` > native `select[required]` (placeholder option "Alege", value "", shown `ink-muted`) + chevron; options boală · șchiopătare · altul (BIRD_EVENT `cull.reason`, D36). Missing on save: `is-error`, `aria-invalid`, error "H1.1: alege motivul pentru 2 găini sacrificate.", Tag `fault` "refuzat", Salvează disabled until chosen; focus goes to the Select. Back to 0 or empty: the Select goes away (the draft keeps the choice).
- **"Fără pierderi azi" checked:** fills 0 in Mortalitate and Sacrificare for every sex present, shown read-only (`input[readonly]` → `sunken`, sex bar kept, value `ink`); Tag `neutral` "fără pierderi"; hints stay; Motiv hidden; "Mai mult" still open. Unchecking restores the previous draft values (empty stays "–").
- **Saved (already entered):** fields read-only, Tag `neutral` "salvat", no "Mai mult"/checkbox; foot: "Salvat la 08:34 · Dr. Ceban" / "poți modifica până la 23:59" (D07) + secondary "Editează" (hidden suffix names the section). Past days for a vet: no Editează (S6 state "Pentru zilele trecute cere managerului.").
- **Tags (≤16 chars, one at a time, worst first):** refuzat (`fault`) > abatere (`warn`) > fără pierderi / salvat (`neutral`, state words, not status); empty or typed-but-unsaved: no Tag.
- **Tokens:** existing only (`panel`, `line`, `rule`, `sunken`, `ink*`, `rec-hen/rooster/mortality/cull`, `warn`/`warn-bg`/`warn-lamp`, `fault`, `control`, `space-1…4`, `radius-*`); vars `--ip-fs-heading`, `--ip-fs-small`, `--ip-fs-figure` from earlier sections.
- **A11y:** labels via `for`; hint + message in `aria-describedby`; warning `role=status`; errors `aria-invalid`; Checkbox is a real hidden input whose focus ring shows on the box; Enter moves to the next CountInput.
- **Preview figures:** sample 16.11.2026 (D27): H1.1 ♀ 4 281 · ♂ 429, ieri ♀ 3 · ♂ 1, media ♀ 1,0 · ♂ 0,3, today ♀ 1 · ♂ 0, culls 0; H1.2 ♀ 4 275 · ♂ 437, ieri ♀ 1 · ♂ 0, media ♀ 0,6 · ♂ 0,1. State examples (D39, footnoted): H1.1 ♀ 4, H1.2 ♂ 4 370, H1.1 ♀ Sacrificare 2 without a reason.
