# OneTimePassword · parola temporară (project addition, SYS12)

The temporary password the app generates when the owner creates a user or resets a password (spec A2 "Shows the new temporary password once"), shown in a Dialog on S22 Utilizatori. It is visible once: closing the dialog discards it. CSS: additions.css section 30. Decided by default (user away), to review.

- **Markup:** inside `div.ip-dialog[role=alertdialog][aria-modal=true][aria-labelledby][aria-describedby=…-once]` (the once Banner is the alert, read as the dialog opens; S22P fix 1) (S22P, D120: the reset confirm turns into this step in place, so one role throughout, and the once-only rule is an alert the owner must act on) (Dialog unchanged; title "Parola nouă pentru Ion Rusu" after a reset, "Parola temporară pentru Observator exemplu" for a new account): `div.ip-otp` (no role: the Dialog names the step, the field has its own label) >
  - `p.ip-otp__ctx`: what happened, in `ink-secondary` with the login in Mono: "Parolă resetată · login ion.rusu" / "Cont nou · Observator · Hîrbovăț · login observator".
  - `label.ip-label[for=…-pw]` "Parolă temporară" above the field (TextField label).
  - `input#…-pw.ip-input.is-readonly.ip-otp__pw[type=text][readonly][value]` with `autocomplete="off" spellcheck="false" autocapitalize="off"` and `aria-describedby` → the once Banner (+ the error line after a failed copy): a real read-only TextField (`sunken`, full width, `control-h-touch` high), password in Plex Mono 500 at the readout size (20/24) in `ink`, the 12 characters spaced by `letter-spacing: space-1` (no groups: an input holds one text value, and a screen reader must read the value itself). Selected text (`::selection`) = `focus` fill + `raised` text (6.1:1), clearly visible on `sunken`.
  - `div.ip-otp__keys`: secondary "Copiază parola" (copy icon). After copying: ok Lamp "copiată" beside it (the key keeps its label and copies again if pressed).
  - `p.ip-err.ip-fieldmsg` (alert icon, section 38) only after a failed copy: "Copierea nu a mers. Parola e selectată: apasă Ctrl+C."
  - Info Banner `#…-once`: "**Se arată o singură dată.** Dă-i-o lui Ion Rusu acum. După ce închizi n-o mai poți vedea; o poți doar reseta din nou."
  - `p.ip-sr[role=status][aria-live=polite]`: "Parola a fost copiată."; empty after a failed copy (SYS13 rule: focus moves to the field, which reads the error line through `aria-describedby`; S22P)
  - Dialog keys `div.ip-dialog__keys` (as every Dialog, FY01): primary "Închide" (the only key; nothing to cancel, the password already exists).
- **Rules:** the password is generated by the app: 12 characters from a–z without i, l, o and 2–9 (no 0/O or 1/l/I to misread when it is read out or typed on a phone), above A1's minimum of 8. It is shown only in this dialog, never stored for display, never in a Toast, the list or the log. Closing (Închide, Esc) discards it; there is no "show again", only another reset. The old password stops working as soon as the reset is saved; the confirm step says so. A deactivated account can't be given a password (reactivate first).
- **On close:** focus returns to the row's Acțiuni key (reset) or to the new user's key in the list (new account); no Toast (the dialog already confirmed it). No confirmation on close, copied or not (a lost password costs one more reset).
- **Keyboard:** the dialog opens with focus on "Copiază parola" (the Dialog's "focus on Anulează" applies to the confirm step; this step has nothing to cancel). Tab order, trapped in the dialog: password (a read-only text input: the screen reader reads label, value and the once rule; ←/→ move the caret and read it character by character; Tab into it selects the value) → Copiază parola → Închide. Enter / Space on Copiază copies, focus stays on it, the live region announces it. A failed copy (clipboard blocked) runs `input.focus()` then `input.select()` on the password, so all 12 characters are selected and Ctrl+C works at once; the error line joins its `aria-describedby`. Esc = Închide. Reset failed (before any password): focus moves to Reîncearcă, whose `aria-describedby` (and the dialog's) → the fault Banner, so it reads "Reîncearcă, buton, Parola lui Ion Rusu nu s-a resetat. …" (see `UserRow/`).
- **States:** shown after reset (focus on Copiază); shown for a new account; copied (ok Lamp "copiată" + announcement); copy failed (focus ring on the password, value selected, error line; the static preview marks the selection with `is-selected`, the same `focus` fill as `::selection`); the reset itself failed (no password, the confirm step's fault Banner + Reîncearcă, documented in `UserRow/`). Hover / pressed from additions.css section 1.
- **Preview only:** `is-selected` fills the whole field, real `::selection` only the text; screens must not use `is-selected` as a field style (it is a stand-in for the static preview).
- **Layout:** the Dialog at `panel-w` (440); desktop only, like S22.
