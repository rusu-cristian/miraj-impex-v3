# FarmSummary (project addition, SYS03)

One panel per farm for a series: S3 › Farm summaries (one per farm under the CycleTrack) and S2 Acasă › owner › farm summaries (compact). CSS: additions.css section 9. Decided by default (user away), to review.

- **Markup:** `article.ip-fsum[aria-labelledby][aria-describedby]` >
  - `.ip-fsum__head`: `.ip-fsum__id` (`h3.ip-fsum__name` > `a` to the farm page at that cycle, inline-flex with a ≥24px target (`--space-6`, D46) and a negative block margin so the 22px heading line does not move · type Tag `ip-tag--neutral` "Ouat" / "Creștere" · guide Tag `ip-tag--neutral` with the guide name, or "fără ghid" per D37) + cycle Lamp + word at the right: `ok` "deschis", `off` "închis", `off` "goală" (cycle-state words, allowed outside the D42 status vocabulary: state, not status, D46).
  - `p.ip-fsum__cycle`: Mono context line, "ciclu din 10.02.2026 · SAPT 40" (open) or "07.10.2025–28.02.2026 · 21 săpt." (closed).
  - `.ip-fsum__alive`: caption + SexCount at readout size (`ip-pair ip-pair--lg`) + "total n" note. Open: "În viață · dd.mm.yyyy". Closed: "Populat · start date" with the placement (alive at close is 0 and says nothing; the transfer-out is a figure line).
  - `dl.ip-fsum__figs` > `div.ip-fsum__fig` per figure: `dt` (record icon `ip-rec--*` 14px + key) · `dd.ip-fsum__val` (Plex Mono 14/20 500 `ink`, right-aligned; ♀ · ♂ as SexCount; unit in `<small>`) · `dd.ip-fsum__sub` (12px `ink-muted`: guide, deviation, week, exclusions, or `ghid: – fără date în ghid`) · optional `dd.ip-fsum__status` (Lamp + word, only where a guide or threshold exists; words only from the D42 Lamp vocabulary: "în normă" / "abatere" / …, the detail such as "+6,8%" or "sub 5 zile" goes in the sub-line). Percent unit: `<small class="ip-fsum__pct">%</small>`, no gap before % (D46).
- **Figures:** laying (open): Ouat azi vs ghid (egg) · Mortalitate cumulată ♀ · ♂ % (skull, no laying guide) · Hrană azi ♀ · ♂ g vs ghid (wheat, D38 weighting, names left-out rows) · Zile stoc ♀ · ♂ (package, short type named in the sub-line with its run-out date and "sub 5 zile": "Cocoși până pe 19.11.2026 · sub 5 zile"; Lamp `warn` "abatere", D19/D42). Growth (closed): Greutate ♀ la transfer vs ghid (scale; ±5% D19, outside → `warn` "abatere", deviation "+6,8%" in the sub-line) · Mortalitate cumulată · Hrană totală ♀ · ♂ g = Σ daily g/pasăre over the days with feed rows vs the guide over the same days (D46), sub-line ghid · deviation · days · ♀ · ♂ kg (wheat; ±10%: `ok` "în normă" / `warn` "abatere") · Transferate ♀ · ♂ (transfer). Every ♀/♂ sign, in keys and sub-lines too, is an `ip-sex` span ("Greutate ♀ la transfer", "medie fără ♀ H4.2 · ♂ H3.2").
- **Variants:** default = narrow (phone; the Lamp sits right of the guide sub-line, which runs under the value up to the Lamp: the value spans the Lamp column too, FIN13B). `ip-fsum--wide` (S3 desktop, 2 columns via `.ip-fsums`): Lamps in a fixed 96px right column, like AlertRow. `ip-fsum--compact` (S2 owner): 12px padding, alive on one line at figure size, 2 figures (Ouat azi, Mort. cumulată; feed stock has its own S2 block). `ip-fsum--touch` (phone): name and next-step links reach 48px without moving the text.
- **Empty farm between cycles:** head (Lamp `off` "goală") + `.ip-fsum__empty`: the EmptyState sentence "Ferma e goală din 28.02.2026. Ultimul ciclu: Seria 2026, 21 săpt." (D1) and the next step `a.ip-link` "Vezi ultimul ciclu". S2 shows a farm as it is today (Telița: empty); S3 shows the farm's cycle in that series (Telița: closed).
- **Container:** `panel`, 1px `line`, `radius-md`, 16px padding; figure rows split by `rule`. No Readout (the page's Readout is the CycleTrack's), no big icons, no colour on values except ♀/♂.
- **A11y:** the farm name is the panel's only link (underlined, ink; hover darkens the underline); the article is labelled by the name and described by the cycle line; key/value pairs are a `dl`; icons `aria-hidden`; every Lamp has its word.
