# CostBlock (project addition, SYS04)

Feed cost per cycle for S11 › Cost (spec D4 §4, screens S11 §5): lei from priced deliveries, lei per bird, lei per egg, and the separate "X kg fără preț" line that is not included (D05, data-model › Feed cost). A compact DataTable, not a KPI-card grid. CSS: additions.css section 11. Decided by default (user away), to review.

- **Markup:** `section.ip-cost[aria-labelledby]` (`.ip-cost--wide` on desktop) >
  - `.ip-cost__head` (`panel`): `h3.ip-cap` "Cost hrană · Seria 2026" + `ip-note` "din livrările cu preț · până pe 16.11.2026".
  - `.ip-cost__scroll` (phone: `role=region`, `tabindex=0`, labelled, so the keyboard can scroll it) > `table.ip-table.ip-cost__table` with a hidden `<caption class="ip-sr">` repeating the head title ("Cost hrană · Seria 2026"): caption headers Ciclu · Kg · Lei · Lei/pasăre · Lei/ou (`th.num` right-aligned).
  - one `tbody` per cycle (split by `line`):
    - cycle row: `th[scope=row]` cycle name ("Hîrbovăț · Seria 2026", 13/18 500 `ink`) + `.ip-cost__sub` (dates as separate Mono spans, `SAPT`, "59 livrări cu preț") · `td.num` priced kg · lei total (whole lei) · lei/pasăre (2 decimals) · lei/ou (2 decimals, laying only; growth: "–" + "creștere, fără ouă").
    - `tr.ip-cost__unpriced`: hidden cycle prefix `<span class="ip-sr">Hîrbovăț · Seria 2026, </span>` (the row header names its cycle to screen readers), then coins icon (`ip-rec--feed`, 16px, `aria-hidden`) + info Tag "fără preț" · unpriced kg in the Kg column · `td.ip-cost__note[colspan=3]` "4 livrări, 04.11–14.11.2026 · neincluse în cost". With none unpriced: plain "fără preț" (no Tag), "0", "Toate livrările au preț." (C6 empty-state sentence).
  - totals `tbody > tr.is-total` (DataTable totals: `line-strong` top edge, `panel`): "Total Seria 2026" + sub "nu include 76 107 kg fără preț".
  - `p.ip-note.ip-cost__foot`: what Lei, Lei/pasăre and Lei/ou are computed on (birds and eggs named, ♀/♂ as SexCount spans).
- **Lei/pasăre = per bird at the start of the cycle** (placed, or arrived by transfer), not per bird alive: it is fixed for a cycle, comparable between cycles, and a closed cycle has 0 alive. Telița: placement 07.10.2025 ♀ 28 080 · ♂ 3 510 = 31 590; Hîrbovăț: arrivals 22–28.02.2026 ♀ 26 765 · ♂ 3 060 = 29 825; series total: per bird placed in the series (31 590).
- **Lei/ou:** lei ÷ total eggs (Cat. 1–3 + Incubabile, D18) of the cycle to date. Laying only.
- **Figures:** Telița Seria 2026 (real, `feed-deliveries.json`): 13 deliveries, all priced, 263 740 kg, 2 031 768 lei → 64,32 lei/pasăre, lei/ou "–". Hîrbovăț Seria 2026 (sample D27, `sample-hirbovat-2026.json` › deliveries, eggs_daily): 59 priced, 1 143 540 kg, 10 417 057 lei → 349,27 lei/pasăre, 5 301 053 eggs to 16.11.2026 → 1,97 lei/ou; 4 unpriced (04.11, 06.11, 10.11, 14.11.2026) = 76 107 kg. Series: 1 407 280 kg, 12 448 825 lei → 394,07 lei/pasăre, 2,35 lei/ou. State example (D39): "Fermă exemplu · Seria 2027", no priced delivery: Kg/Lei/Lei/pasăre/Lei/ou "–" ("nicio livrare cu preț"), 8 000 kg fără preț.
- **Formats:** U+202F thousands, decimal comma, whole lei for totals, 2 decimals for unit costs, unknown "–" with its reason.
- **Layouts:** default = phone (DataTable rule): horizontal scroll, the first column sticky at 160px with a `rule` edge, its sub-lines wrap. `.ip-cost` has no `overflow:hidden`, so the scroll region's focus ring (2px, 2px offset) shows whole; the head and foot round their own outer corners with `radius-md` (with no foot, the scroll region rounds its bottom corners). `ip-cost--wide` (desktop): row headers on one line, no sticky edge.
- **Roles (D06):** owner, manager and viewer see the same read-only block (no difference in markup: prices are edited in the Livrări table / S12, never here). Vets never get it: the screen does not render the section (not hidden with CSS).
- **Tokens:** `raised`, `panel`, `line`, `line-strong`, `rule`, `ink`/`ink-secondary`/`ink-muted`, `info`/`info-bg` (Tag), `rec-feed` (coins, 6,1:1 on raised), `radius-md`, `space-2/3`; new var `--ip-fs-table/--ip-lh-table` (13/18) names bundle.css's `.ip-table` text size. No new colours.
- **Coins icon:** the system names a coins icon for prices but ships no path; this uses Lucide "coins" (1.75 stroke): `<circle cx="8" cy="8" r="6"/><path d="M18.09 10.37A6 6 0 1 1 10.34 18"/><path d="M7 6h1v4"/><path d="m16.71 13.88.7.71-2.82 2.82"/>`.
