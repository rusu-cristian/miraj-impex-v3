# GuideChart variants (project addition, SYS06)

The GuideChart variants the S4 tabs need (spec D1: Păsări, Hrană, Greutate, Producție), drawn on a Readout with the GuideChart vocabulary (grid `readout-line`, dashed `readout-guide` + `readout-band`, actual `readout-ok`, extra series `readout-2…4` each with its own dash, today line, X axis = SAPT of the cycle, no animation). CSS: additions.css section 16. Demo data: Hîrbovăț Seria 2026 (sample, D27), SAPT 1–40.

- **Markup (D42/D44, every focusable chart):** `svg.ip-chart[role=group][aria-roledescription=grafic][tabindex=0]` with `aria-label` and `aria-describedby` = hidden help line (`.ip-sr`) + the readout; the drawing sits in one `<g aria-hidden="true">`; under it `div.ip-chart__read[role=status][aria-live=polite]` (←/→ week cursor `.cur`, Home/End; starts on today) and a hidden `table.ip-sr` with `thead th[scope=col]` and one `th[scope=row]` per SAPT. Weeks without data are rows with "– fără date" (never 0).
- **Two-sex series:** ♀ = `.act` (`readout-ok`, solid), ♂ = `.s2` (`readout-2`, dash 8 3), cursor dots `.pt` / `.pt2`. `rec-hen` (2,81:1) and `rec-rooster` (2,74:1) fail 3:1 on the `readout` ground, so the RecordCode sex colours don't go on the dark chart; the legend carries the ♀/♂ sign (`readout-ink`) and the word. Light-surface charts (small curve) keep `rec-hen` / `rec-rooster`.
- **Legend:** `div.ip-chart__legend` on the Readout: 24×8 line swatch (the series' own class) + sign + word, then the note (base, guide state). Extra classes `.s3` (`readout-3`, dash 2 3), `.s4` (`readout-4`, dash 12 3 2 3), `.pt3`, `.pt4`.
- **Mortalitate % (Păsări):** cumulative ♀ and ♂, % of placement (♀ 26 765 · ♂ 3 060), 0–15%. No guide (D29): caption lamp `ip-rlamp--off` "FĂRĂ DATE ÎN GHID", readout "ghid – fără date în ghid". SAPT 40: ♀ 5,54% · ♂ 11,93%.
- **Hrană kg/zi (Hrană):** two lines by feed type (Breeder 2 ♀ `.act`, Cocoși ♂ `.s2`), weekly mean kg/day, 0–6 000 (not stacked). The guide is per bird, so no guide line here (it's drawn on the g/pasăre chart); the caption lamp compares kg with guide g × birds on the same rows (D46), ±10% (D19): SAPT 40 ♀ −0,4% · ♂ +0,8% → în normă.
- **Uniformitate · CV (Greutate):** ♀, uniformity `.act` (legend "uniformitate · păsări în ±10% din medie") and CV `.s2` on one 0–100% axis, means weighted by sample size; no guide → "FĂRĂ DATE ÎN GHID".
- **Incubabile % (Producție):** incubabile ÷ total ouă (D18), 0–100%; guide drawn if the guide has it, else (Ross 308 ouat, D29) the off lamp. Hidden table: "Incubabile, % din total ouă" (%) and "Ouă incubabile din total ouă" (counts, "127 131 din 130 921"); SAPT 3 "– fără ouă" in both.
- **Masa oului, g (Producție):** weighted by eggs, axis 40–70 g; no guide.
- **Small curve** (`svg.ip-spark`, 160×48, `--ip-spark` = 3×48+16): actual + guide only, no axes, no band, last point r 2; not focusable, `role=img` + `aria-label` naming the last value and guide; the figures sit beside it (table row or Readout value). On light steel (DataTable cells, S20 guide detail): actual `ink` (or `rec-hen`/`rec-rooster` for ♀/♂ figures, ≥4,5:1), guide dashed `ink-muted`. Inside `.ip-readout`: readout tokens (♂ `readout-2` dashed). Table: `table.ip-table.ip-table--rowheads.ip-sparktable` (row headers: additions.css §32, FIN14) inside `div.ip-tablescroll[tabindex=0][role=region][aria-label]` (DataTable phone rule: scrolls in its own box, first column sticky), curve column `td.ip-sparktable__curve`, row headers `th[scope=row]` in body type.
- **Formats:** D46 (no space before %: "5,54%"), U+202F thousands, true minus, `SAPT 40` in Mono.
- **Phone (fix 1):** every variant uses the GuideChart phone pattern (two drawings in `div.ip-chartbox`, 320-wide phone viewBox, X ticks 1 · 20 · 40, ≤3–4 Y ticks); no sideways page scroll at 390.
