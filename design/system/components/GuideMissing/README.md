# Guide missing states · Stat and GuideChart (project addition, SYS01)

How Stat and GuideChart look when there is nothing to compare with (spec D1 "no guide", D22, D29).

- **Stat, no guide data for this indicator** (the farm has a guide, the guide has no figure here: laying body weight, laying mortality, egg weight, CV): the guide line reads `ghid: – fără date în ghid` in `.ip-stat__guide`. No Tag, no Lamp, no deviation. Demo: Hîrbovăț on 16.11.2026 (sample, D27).
- **Stat, farm has no guide:** the guide slot holds `ip-tag ip-tag--neutral` "fără ghid" (neutral: missing reference, not a flock status). No deviation. Demo farm labelled "Fermă exemplu" (no real farm is guide-less).
- **GuideChart, partial guide:** the dashed guide and its band stop at the guide's last week, with an end cap (`.gend`, `readout-guide`, 1.5px) and an axis-style note "fără date în ghid după SAPT 23"; the actual line runs on. Caption lamp: `ip-rlamp--off` "FĂRĂ DATE ÎN GHID" when the shown week has no guide figure; the sub-line repeats the note. Demo (D38a): "Fermă exemplu · creștere", weight ♀ vs the growth guide, whose body weight is real for SAPT 1–23 (guide-growth.json); the actual curve is sample.
- **GuideChart, no guide:** actual only, no guide, no band; caption lamp `ip-rlamp--off` "FĂRĂ GHID" (hollow ring in `readout-muted`); sub-line "ciclul nu are ghid, nu se compară". Demo: "Fermă exemplu".
- **Keyboard week readout (every focusable `svg.ip-chart`, GuideChart spec):** the SVG has `tabindex="0"`, `role="img"`, an `aria-label`, and `aria-describedby` = a hidden help line + the readout. ← / → move a week cursor (`.cur`, hairline `readout-muted`, with `.pt` on the actual); Home / End jump to the first / last week; the cursor starts on today / the last week. `div.ip-chart__read[role=status][aria-live=polite]` under the chart (Plex Mono 12, `readout-ink`) names the week, actual, guide and deviation: "SAPT 12 · efectiv 1 395 g · ghid 1 450 g · −3,8 %"; past the guide "ghid – fără date în ghid"; no guide "ghid – fără ghid". Focus: the system ring on the SVG.
- **Accessibility:** the hidden data table (`table.ip-sr`) lists every week and writes "– fără date în ghid" / "– fără ghid" in the guide column.
