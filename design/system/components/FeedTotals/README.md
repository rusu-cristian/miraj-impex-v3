# FeedTotals (project addition, SYS02)

The per-feed-type totals block under the AllocationRows in Hrană zilnică (spec C2 step 4, screens S7 step 4), plus a compact variant for the SaveBar summary.

- **Markup:** `section.ip-ftot[aria-labelledby]` > `.ip-ftot__head` (`h3.ip-cap` "Total pe tip de hrană" + `ip-note` "16.11.2026 · doar rânduri confirmate") > one `div.ip-ftot__row[role=group][aria-label="Breeder 2, pentru găini"]` per feed type used today at the farm > `.ip-ftot__foot` (`ip-note`: how days left are computed, the threshold).
- **Row:** `.ip-ftot__type` (RecordTile `ip-tile ip-rec ip-rec--feed` with the wheat icon, `aria-hidden`; `.ip-ftot__name` type name + for-sex sign as `ip-sex--hen|rooster`, `aria-hidden` since the group label names the sex; `.ip-ftot__sub` "5 din 6 rânduri confirmate") · three `.ip-ftot__cell` (`--kg` Azi, `--stock` Stoc după azi, `--days` Zile rămase), each `.ip-ftot__key` + `.ip-ftot__val` (Plex Mono 16/20 500 `ink`, like the AllocationRow kg it sums; unit in `<small>`) + `.ip-ftot__sub` · `.ip-ftot__status` (Lamp + word) · optional `.ip-ftot__msg` (warn Banner, `role=status`).
- **Figures:** Azi = Σ kg of **confirmed** rows of that type (live; one decimal, as AllocationRow); sub-line names what's left out ("fără ♀ H4.2"). Stoc după azi = stock at the start of the day − Azi (whole kg; sub "din 31 584 kg"). Zile rămase = stoc după azi ÷ average daily consumption of the last 3 days (13–15.11.2026), one decimal; sub "până pe 23.11.2026".
- **Status (Lamp + word):** `ok` "în normă" (≥ 5 zile) · `warn` "abatere" (< 5 zile, D19) · when the stock after today would go below 0: `warn` "abatere" (D50: lamp words stay in the D42 vocabulary) with "stoc sub 0" as the first sub-line of Stoc după azi (then "din 2 093 kg"). A **warning, not a refusal** (D40): the row gets the warn Banner with the spec C2 sentence ("Stocul de Breeder 2 la Hîrbovăț ar ajunge la −1 240 kg. Verifică livrările."), days left "0,0" "se termină azi", and Salvează stays enabled. Figures stay `ink`; only ♀/♂ and the tile carry record colours.
- **Before any row is confirmed:** Azi "–" with "nimic confirmat"; stock = stock now ("stoc acum"), days left from it; status computed from it. SaveBar disabled.
- **Layouts:** phone (default, 390 with 16px page edge): type line with the lamp on the right, then the three figure cells right-aligned. `ip-ftot--wide` (desktop): one line per type under an `aria-hidden` column header (`.ip-ftot__cols`: Tip de hrană · Azi · Stoc după azi · Zile rămase · Stare), per-cell keys kept for screen readers only, status in a fixed 120px column so lamps line up.
- **Compact (SaveBar):** `span.ip-savebar__sum.ip-ftot-sum` > two `.ip-ftot-sum__line`, each segment one no-wrap flex item (S7P, additions.css §20): wheat (`ip-rec--feed`) + "10 din 12 rânduri ·" + "3 691,3 kg"; then one Lamp for the stock, worst type first, with its detail ("abatere" + "Cocoși 3,9 zile"; stock below 0: "abatere" + "Breeder 2 · stoc sub 0", D50; ok "în normă" + "stoc"). Counts rows (section × sex), not sections: 6 sections hold 12 rows. "n de confirmat" is not repeated (S7P: it is m − n). Nothing confirmed: "0 din 12 rânduri · – kg", Salvează disabled. Two lines at 390.
- **Tokens:** `panel`, `line`, top `line-strong`, `rule` separators, `radius-md`, `space-2/3/4`, `ink`/`ink-secondary`/`ink-muted`, `rec-feed(-bg)`, `rec-hen`/`rec-rooster`, `ok/warn/fault` + lamps, `warn-bg` (Banner), `--ip-fs-alloc/--ip-lh-alloc` (16/20, mirrors bundle.css `.ip-alloc__kg`). No new colours.
- **A11y:** static block (no targets); each type is a labelled group; keys stay readable to screen readers in the wide layout; the stock warning is `role=status` (announced once when it appears; the live kg figures are not a live region, to avoid announcing every keystroke). Lamps always carry their word. Contrast: figures `ink`, sub-lines `ink-muted` on `panel` (≥4.5:1).
- **Figures (preview):** recomputed from `sample-hirbovat-2026.json` for 16.11.2026 (sample, D27): Breeder 2 ♀ 5 of 6 rows 3 332,5 kg, stock 31 584 → 28 252 kg, 7,1 zile (÷ 3 976 kg/zi), until 23.11.2026; Cocoși ♂ 5 of 6 rows 358,8 kg, 2 009 → 1 650 kg, 3,9 zile (÷ 419), until 19.11.2026; together 3 691,3 kg, H3.2 ♂ and H4.2 ♀ still to confirm. All confirmed with yesterday's suggestions: 4 398,9 kg. The −1 240 kg row is the spec C2 example, a state example only (D39).
