# MissingRow · Lipsesc date (project addition, SYS08)

An EventRow variant for spec C9 / D2 / screens S2 (vet item 2, manager item 5): sections with birds and no Zilnic or no Hrană zilnică entry for a day. Shown for today from 12:00 (D19) and for up to 7 days back. CSS: additions.css section 23. Decided by default (user away), to review.

- **Block:** `section.ip-missing[aria-labelledby]` > `.ip-missing__head` (`h2.ip-cap` "Lipsesc date" + `p.ip-note` scope: "Hîrbovăț · azi de la 12:00 · ultimele 7 zile", times and counts in `span.ip-num`; manager with several farms: "fermele tale · …") > `.ip-list` of rows.
- **Row = section × entry × day**, newest day first, then section order. `a.ip-ev.ip-ev--missing[href]` opens the form at that section and day:
  - RecordTile (`aria-hidden`): Zilnic = mortality skull; Hrană zilnică = feed wheat (as the BottomSheet Înregistrează menu).
  - `.ip-ev__main` > `.ip-ev__title` (500): hidden "Completează: " + [farm · when the user has more than one farm] + section · entry + for feed the missing sex(es) as SexCount signs with hidden "găini"/"cocoși" in `span.ip-ev__type` (type and sign kept on one line, `white-space:nowrap`, additions.css §23). Meta (`ip-ev__meta ip-num`, shown as a block line by §23, no inline style): `dd.mm.yyyy · SAPT 40 ·` birds alive (♀/♂ coloured) · for feed "ieri 157 g" when yesterday has grams.
  - `.ip-ev__status`: warn Lamp **lipsă** (D42 vocabulary). `.ip-ev__go`: 16px chevron-right (Lucide), `ink-muted`.
- **Locked (past day, vet):** D07 lets vets enter only today, so a past day is `div.ip-ev.ip-ev--missing.is-locked` (not a link): neutral Tag "blocat" after the title (EventRow's locked rows), meta "zi trecută · o completează managerul", lamp kept, chevron slot empty (lamps stay in one column). Managers get the same day as a link.
- **States:** default (link) · hover `sunken` · pressed `rule` (chevron and lamp word → `ink-secondary`, D34a) · focus ring (row takes the list's corners) · locked · before 12:00 with past days missing (scope "Hîrbovăț · 10:40 · …": past-day rows only, today is not listed yet) · empty after 12:00 (`p.ip-missing__empty`: off Lamp "nimic lipsă" + "Toate secțiunile cu păsări au Zilnic și Hrană zilnică în ultimele 7 zile.") · before 12:00 with nothing missing ("Zilele 09.11.2026–15.11.2026 sunt complete. Lipsurile de azi apar de la 12:00."; in both empty sentences "7" and "12:00" are `span.ip-num`) · loading (`ip-ev--skel` rows, static `ip-skel`, `aria-busy` on the section).
- **Contrast (D66):** on a pressed row the ♀ figure in the meta (`rec-hen` on `rule`) is 4.46:1 (♂ 4.57:1). Accepted as a momentary state (as D34a), flagged for the system artifact.
- **Never listed:** sections without birds (Telița, empty since 28.02.2026); feed rows that are only unconfirmed suggestions are listed (D13: unconfirmed = missing once saved).
- **A11y:** each link is one row with a full name; lamps carry their word; status isn't a live region. Phone: rows ≥ 48px, whole row is the target.
- **Sources:** `sample-hirbovat-2026.json` › `allocations_today` (16.11: H3.2 ♂ 426, ieri 157 g; H4.2 ♀ 4 107, ieri 156 g) — sample (D27). Zilnic H1.1 lipsă, H4.2 ♀ on 15.11 and the empty lists are state examples (D39).
